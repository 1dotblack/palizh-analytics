## 3. Баги и ложные успехи

| ID | Что в коде | Чем обернётся на собрании / тесте |
|----|------------|-----------------------------------|
| **D12** | `order.vue`: `date: 'null'`, `comment: 'null'` | В 1С уйдёт строка `null`; заказ «создался», данные битые |
| **M404** | Меню Документы / Обучение | Клик на демо = 404 |
| **F5** | `orders/[id].vue` → `getMockOrderExtras()`, `mock-tracking-desktop` | «Документы и трек» не из API |
| **SHADES** | `FilterPanel` → `mockColorGroups` | Фильтр оттенков не про данные 1С |
| **NS** | `RequestDrawer.submit` без fetch | Success без заявки в БД |
| **B7-FE** | Форма claims шлёт `order_id` | Бэк не проверяет владельца — FE не может «закрыть» это UI-ом |

**Закрыто vs 08-07:** нет route КТ (**F2**), checkout без POST (**D10**).

## 4. Рассинхроны фронта с BE / 1С / Инфарх

| Слой | Рассинхрон |
|------|------------|
| Backend | Документы: API есть, UI нет / моки |
| Backend | Claims: UI есть, ownership нет |
| Backend | Consent: ЧТЗ/форма ожидают — API нет |
| 1С | Checkout `'null'` портит `post_orders` |
| 1С | Оттенки mock ≠ характеристики/HEX из обмена |
| Инфарх | Документы и обучение в ЛК vs 404 и публичный URL обучения |
| ЧТЗ | Нестандарт как сценарий vs заглушка success |

URL-фильтры каталога в целом **сходятся** с заданием query-first `/catalog` (частично уже в коде). Не путать с фильтром оттенков.
