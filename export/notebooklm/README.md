# Выгрузка документации Palizh для NotebookLM

> **Политика (2026-06-29):** пересборка bundle и синхронизация с блокнотом — **только по явному запросу** команды (`./tools/sync_notebooklm.sh`), не при каждом аудите или правке ЧТЗ.

Собранный каталог содержит **набор источников** (Markdown-файлы в `bundle/`) — ниже лимита **50** на ноутбук (тариф NotebookLM Standard). Документы **сведены поблочно** в несколько больших Markdown-файлов; спецификации OpenAPI вынесены в **отдельные YAML** без дублирования клиентских и входящих 1С-спек (используется сборка **`openapi_mvp_merged.yaml`**).

## Пересборка

Из корня репозитория:

```bash
ruby tools/build_notebooklm_bundle.rb
```

При изменениях клиентских / 1С OpenAPI перед сборкой имеет смысл заново выполнить merge по правилам в `Техническая часть/OpenAPI_индекс.md`. Команда (рабочая директория — **`Техническая часть/`**):

```bash
ruby tools/merge_openapi_mvp.rb
```

Результат: каталог **`bundle/`**, манифест **`MANIFEST.md`** (рядом с этим README).

## Состав bundle

| № файла в bundle | Назначение |
|------------------|------------|
| `01_…14` | см. столбцы в `MANIFEST.md` после сборки или список в `SOURCES.md` |
| `09_…yaml` … `12_…yaml` | OpenAPI MVP merged, публичный HTTP, платформа→1С, post-MVP |

## Целевой блокнот и синхронизация

- **Файл с ID:** [NOTEBOOK_TARGET](NOTEBOOK_TARGET) — здесь задаются `NOTEBOOK_ID` и `NOTEBOOK_TITLE` для блокнота «Palizh b2b площадка» и др.
- **Одна команда — пересборка локального bundle и полная замена источников в блокноте** (не дублирует файлы; сначала удаляет текущие источники через CLI):

```bash
./tools/sync_notebooklm.sh
```

Перед первым запуском: **`notebooklm login`**; в PATH должны быть **`notebooklm`** и **`python3`**.

### Исключения (что сознательно не попадает в bundle)

См. раздел «Исключено намеренно» в `MANIFEST.md` (сырые транскрипты, архив аудитов, дубль `openapi_client`/`openapi_1c_inbound`, дубль `входящие/1c-http-openapi.yaml` и т.д.).

Сценарий обновления в NotebookLM описан в **[Сценарий_обновления_NotebookLM.md](Сценарий_обновления_NotebookLM.md)**.
