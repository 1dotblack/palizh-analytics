# Список источников для одного блокнота Palizh

После сборки каждая строка соответствует **одному** источнику в NotebookLM. Для блоков **09–12** в `bundle/` лежит и **`.yaml`**, и одноимённый **`.md`** (Markdown с телом спецификации в блоке fenced `yaml`); **`sync_notebooklm.sh` загружает только `bundle/*.md`**.

| № | Файл в `bundle/` (для загрузки) | Содержание |
|---|-----------------|------------|
| 1 | `01_README_и_план_проекта.md` | README репозитория, план на старте |
| 2 | `02_ЧТЗ_полный.md` | Все ЧТЗ подряд от оглавления до 14 блока |
| 3 | `03_Понимание_задачи.md` | `Понимание задачи/Понимание_задачи.md` |
| 4 | `04_Инфарх.md` | Все файлы каталога `Инфарх/` |
| 5 | `05_USCases_и_роли.md` | `uscases/`: роли, сценарии, потоки дизайна |
| 6 | `06_Техническая_часть_архитектура.md` | Архитектура, стек, NFR, CI/CD, наблюдаемость, админ-маршрутизация и пр. |
| 7 | `07_Техническая_часть_интеграция_1С_и_контракты.md` | 1С, модель каталога, контракты, email-регламент MVP (`EMAIL_*`), задания разработчикам |
| 8 | `08_OpenAPI_комментарии_и_индекс.md` | OpenAPI индекс и пояснения к блокам MVP (только Markdown) |
| 9 | `09_openapi_mvp_merged.md` *(рядом `09_openapi_mvp_merged.yaml` — не в блокнот)* | client + 1С inbound |
| 10 | `10_public_http_openapi.md` *(+ `.yaml`)* | Публичный HTTP API |
| 11 | `11_1c_http_openapi.md` *(+ `.yaml`)* | Платформа → публикации 1С |
| 12 | `12_openapi_post_mvp.md` *(+ `.yaml`)* | Черновик post-MVP |
| 13 | `13_Интервью_саммари_и_реестры.md` | Саммари, реестры, материалы встреч (без транскрайбов; **без аудита документации**) |
| 14 | `14_Входящие_webhooks.md` | `входящие/incoming-hooks.md` |

Под обновление манIFEST/SOURCES см. заголовки в этом файле: при расширении набора блоков синхронизируйте с `tools/build_notebooklm_bundle.rb`.
