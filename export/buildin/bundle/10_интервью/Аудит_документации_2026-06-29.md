## 1. Краткое видение проекта

Palizh — **B2B-платформа** (витрина + ЛК) для клиентов с контрагентом и договором в **1С ERP 2.5.22**. Ядро MVP: каталог с персональными ценами после входа, **корзина с расчётом на backend (вариант A)** — смешанная строка (`amount` за штуку, `amountPerBox` за коробку), **`lineTotal` по позиции** (отдельного прайс-листа клиенту нет), оформление заказа, счёт из 1С, **6 статусов** в ЛК, документы, доставка/самовывоз, email-уведомления, претензии, онбординг, админка.

Интеграция: **`POST /exchange`** (1С → платформа), заказы — **`POST /post_orders`**, документы — **`GET /get_documents`**. Канон публичного API стенда — **`public-http-openapi.yaml`** (GitLab `docs/`). Поиск — **на платформе** (`GET /search/products`), без Ensi. Адреса — **DaData**, `deliveryAddress` + `deliveryAddressFiasId`.

**Сильные стороны (после правок 2026-06-02…29):** согласованы цены корзины (ЧТЗ 01 §4.2.4, ЧТЗ 06, `Принятые_решения` §4, маппинг 1С, public-http `CartItem`); поиск без Ensi в ЧТЗ 11 и планах бэка; **№57 закрыт**; канон `ProductPrice` и поиск в OpenAPI.

**Главные разрывы сейчас:** **код стенда vs спека** (поиск, поля корзины, `/claim` vs `/claims`); **зеркала `export/buildin/`**; **ЧТЗ 04** без канона API претензий; **нет чек-листа приёмки** корзины vs счёт 1С; открытые **№18, №30, №34**.
