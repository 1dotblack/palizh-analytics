# Тест стилей Markdown → Buildin

Эталонная страница для проверки конвертации при выгрузке документации Palizh.

## Заголовки и текст

Обычный абзац с **жирным**, *курсивом*, `инлайн-кодом` и [ссылкой на репозиторий](https://github.com).

### Списки

- Маркированный пункт с **акцентом**
- Второй пункт с `кодом`

1. Нумерованный шаг один
2. Нумерованный шаг два

> Цитата: as-is и to-be не смешивать в одном блоке требований.

## Шаги для макета
