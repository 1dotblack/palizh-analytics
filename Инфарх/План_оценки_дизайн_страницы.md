# План оценки дизайна: страницы, scope, пробелы

**Назначение:** сверка оценки дизайнера с актуальным scope (Инфарх, ЧТЗ).  
**Дата:** 2026-05-27  
**Источники:** [состав-и-задачи-страниц.md](состав-и-задачи-страниц.md), [информационная-архитектура.md](информационная-архитектура.md), [видение-и-границы.md](видение-и-границы.md), ЧТЗ 01–14.

**Легенда колонок**

| Колонка | Значение |
|---------|----------|
| **Scope MVP** | `да` — входит в MVP; `post-MVP` — явно позже; `нет` — не делаем |
| **В оценке** | Есть в текущем плане/дооценке дизайнера |
| **Риск** | `высокий` — риск недооценки или незакрытого решения; `средний`; `низкий` |

## Сводка по пробелам (что упустили)

| Проблема | Рекомендация |
|----------|--------------|
| Нет разделов ЛК: **Документы**, **Уведомления**, **Обращения и претензии**, **Заявки на обучение** (история), **Отложенная корзина**, **Адреса доставки** | Добавить в план оценки (хотя бы список + ключевые состояния) |
| **Страница акции** (detail) отдельно от листинга «Акции» | +1–2 ч к блоку акций или явно «входит в 2 ч» |
| **Карточка заказа** / 6 статусов / сбой синка с 1С | Уточнить, входит ли в «ЛК. Заказы» или нужен отдельный подплан |
| **Главная**, **Карточка товара**, **Каталог** (деск доработка) | Частично есть; проверить полноту состояний (гость/авторизован, две цены, виджет обучения) |
| **Стать клиентом** vs **Регистрация** | Единая форма заявки **без пароля**; пароль — по письму после 1С (ЧТЗ 05) |
| **Обучение в ЛК** | **Да:** раздел «Обучение» + **«Заявки на обучение»** (история, статус `Отправлено`). Не путать с публичным «Обучение» на витрине |
| **UI-kit / компоненты** | Отдельно от экранов; заложить состояния для всех форм и списков |

## Обучение: ответ на открытый вопрос

| Вопрос | Ответ по документации |
|--------|------------------------|
| Будет ли обучение в ЛК отдельной вкладкой? | **Да:** в IA есть `ЛК → Обучение` и отдельно `Заявки на обучение` |
| Будет ли история обучения? | **Да, но узко:** только **история отправленных заявок** со статусом **`Отправлено`** (без смены статуса, без 1С). Полноценная «история обучения / сертификаты / календарь» — **post-MVP** (ЧТЗ 14, Инфарх) |
| Что уже в дооценке 4+2 ч? | **4 ч** — ближе к **публичному** разделу (листинг + карточка, моб/деск). **2 ч** — форма заявки. **Не покрыто:** ЛК «Заявки на обучение» и навигация ЛК→Обучение |

**Рекомендуемая дооценка обучения:** +2–4 ч на `Заявки на обучение` (список + detail) и явное разделение макетов «витрина / ЛК».

## Post-MVP и вне scope (не оценивать в MVP-плане)

| Элемент | Scope |
|---------|--------|
| ЛК менеджера | нет |
| FAQ / Вопрос-ответ отдельным разделом | нет |
| Онлайн-конфигуратор колеровки | нет (форма в ЛК) |
| Отмена заказа из ЛК | post-MVP / вне MVP |
| История бонусов, списание бонусов | post-MVP |
| Оптовый заказ по Excel | post-MVP |
| Плашка «акционный товар» в листинге | под вопросом (ЧТЗ 06 §5) |
