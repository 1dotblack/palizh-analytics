# Архив

Папка для устаревших артефактов: отчёты аудитов прошлых дат, снимки документов, **устаревшие артефакты Инфарх**, которые уже не актуальны, но должны быть доступны для истории.

**Что НЕ кладём в архив:**
- Снимки «Понимание задачи» по крупным изменениям — у них отдельная папка `Понимание задачи/архив/`.
- Транскрипты и саммари интервью — они остаются в `Интервью и встречи/` с датой в имени.

**Правило:** при появлении нового отчёта аудита в **корне** репозитория (`Аудит_документации_ГГГГ-ММ-ДД.md`) предыдущий отчёт (включая последний в корне) переезжает в `архив/`. **Дата в имени файла** — календарный день **прогона аудита** (когда сформирован отчёт), а не дата каждой последующей правки по рекомендациям. *По состоянию на 2026-06-29 актуальный файл в корне — `Аудит_документации_2026-06-29.md`; предыдущий в корне — `архив/Аудит_документации_2026-06-02.md`.*
