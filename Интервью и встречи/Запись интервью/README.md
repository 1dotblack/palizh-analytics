# Записи интервью (исходные медиа)

Файлы **видео и аудио** из этой папки **не коммитятся в Git** (см. корневой `.gitignore`) — из‑за лимитов GitHub и размера репозитория.

Храните записи **локально** или в корпоративном облаке. Для проекта в репозитории используются **саммари** (`../Саммари/`) и при необходимости **транскрипты** (`../Транскрайб/`).

**Одна встреча — один медиафайл.** Если для одной и той же записи есть и видео (.mp4/.webm), и отдельное аудио (.mp3), оставляйте **один** вариант (обычно меньший по размеру при том же содержании: для интервью это часто .webm или .mp3; для записи без отдельного mp3 — один из форматов видео). Дубликаты той же записи в каталоге проекта «Агент обработки встреч» (`meets/`) после выгрузки транскрайба в `Транскрайб/` не нужны — переносите единственный эталон сюда или наоборот, но не держите две копии одного файла в разных папках.
