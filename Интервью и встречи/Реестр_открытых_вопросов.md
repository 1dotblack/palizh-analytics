# Реестр открытых вопросов

Сводный список открытых вопросов по проекту для уточнения с клиентом. Источники: ЧТЗ 01–14 (разделы «Открытые вопросы»), документ [Вопросы_клиенту_по_процессу_заказа.md](Вопросы_клиенту_по_процессу_заказа.md). После получения ответов — переносить в соответствующие ЧТЗ/Понимание задачи и помечать здесь как закрытые.
